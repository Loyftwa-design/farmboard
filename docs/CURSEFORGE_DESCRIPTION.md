# Farmboard

**Farmboard** is a lightweight farming progress tracker for **World of Warcraft: Midnight**.

Create multiple customizable farming boards, drag items into tracking slots, set collection goals, and monitor your progress directly in-game.

Farmboard is designed to stay simple and lightweight while giving you a clear overview of materials, reagents, fish, ore, herbs, or any other items you want to farm.

## Features

- Add items via **drag & drop**
- Create **multiple independent Farmboards**
- Set custom farming goals from **1 to 9999**
- Track items in **bags, character bank, and Warband/Account Bank**
- Display **Midnight crafting/reagent quality**
- Configure **1 to 24 slots** per board
- **Horizontal and vertical layouts**
- Movable and lockable boards
- Rename and duplicate boards
- Show, hide, reset, and delete individual boards
- **Minimap button** with global Farmboard management
- Visual marker when a farming goal is completed
- Custom goal-complete sound
- Center-screen **"- Ziel Erreicht! -"** notification
- Persistent settings through SavedVariables
- No external libraries required
